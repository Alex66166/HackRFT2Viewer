# 1.4.2-RC1

- Ускорены синдромы BCH; после исправления проверяется кодовое слово.
- Исправлены scalar/SIMD LDPC validity, QPSK parity bypass и cell permutation при TI=0.
- BCH получает остаточные ошибки LDPC; метаданные common PLP не подменяются.
- Неполные SIMD-пакеты выгружаются каждые 200 мс.
- Добавлены ненулевые тестовые кодовые слова и воспроизведение cs8 без оборудования.
- Журналы сохраняются по сеансам с ограничением размера; экспорт включает FEC и DSP.
- Захват cs8 сохраняется атомарно с JSON-параметрами.
- Windows-сборка зависит от native-тестов с ASan/UBSan.
- Из предоставленной эфирной записи TS пока не получен: версия имеет статус RC.

# 1.4.0

- Передний DSP-тракт переведён с Farrow → 18.285714 MS/s → FIR64/2 на прямой 32-tap polyphase FIR-resampler к DVB-T2 sample rate 64/7 MS/s.
- Исправлен расчёт ёмкости буфера после ресемплинга при входе 8 MS/s; исключена возможная запись за границу массива.
- Убран `qDebug()` на каждом `dvbt2_demodulator::reset()`, который усиливал перегрузку при потере синхронизации.
- Очередь I/Q сокращена с 64 до 24 блоков. При переполнении устаревший backlog сбрасывается целиком, а свежий блок сохраняется для быстрой ресинхронизации.
- Счётчик backlog теперь учитывает только действительно ожидающие блоки, а не блок, уже находящийся в DSP.
- Release-сборка использует `-O2 -mavx2 -msse4.1`.
- Интерфейс и метаданные версии обновлены до 1.4.0.

# 1.3.0

- PLP публикуется сразу после успешной проверки L1-post, до первого корректного BBFRAME; в интерфейсе это позволяет отличить найденную DVB-T2 конфигурацию от уже найденных телеканалов.
- При отсутствии TS/PAT/SDT сервисный список показывает понятное состояние «PLP найден — ждём TS/PAT/SDT», а VLC и автоматическое сканирование не считают шумовой L1-lock телеканалом.
- USB I/Q обрабатывается ограниченной очередью блоков с одним пакетным событием DSP; сохранены номера блоков и сброс синхронизации при реальном разрыве.
- Добавлен режим входного потока 8 MS/s для компьютеров, на которых 10 MS/s перегружает DSP.
- Версия portable/source и служебные документы обновлены до 1.3.0.

# 1.2.0

Исправления по скриншотам 1.1: P1 найден, L1 PRE/POST = 0, DSP = 100%, потери буферов.

- Исправлена четырёхкратная ошибка масштаба оценки частотного смещения P1.
- Коррекция частоты цифровая и непрерывная по фазе; исключены RF-перестройки и 120 мс паузы на каждую поправку.
- Защитный интервал определяется по CP на первом P2; перебор по нескольким кадрам для каждой гипотезы убран из пути захвата.
- Исправлен знак интерполяции фазы через +π в P2, data и frame-closing эквалайзерах.
- Полноценная коррекция L1-pre и одноблочного L1-post: BCH/LDPC, сокращение и депунктирование; мягкие LLR для L1-post.
- Устранены неверный размер BPSK-буфера L1-post и чтение за концом блока; проверяются границы полей.
- Исправлены кольцевые суммы P1, безопасное чтение истории и повторная проверка P1-кандидатов.
- NCO без вызова sin/cos на каждый отсчёт; целочисленная статистика АЦП.
- Фазовая поправка применяется один раз на символ, частотная ошибка CP пересчитывается в единицы входного потока.
- Номера USB-блоков позволяют обнаруживать разрывы очереди и сбрасывать синхронизацию.
- Запись 3 с исходного I/Q до очереди DSP; запись в файл вынесена из USB callback.
- Исправлено освобождение и повторное выделение массивов пилотов и OFDM-символов; запуск рабочих потоков синхронизирован перед возможной остановкой.
- Верный статус поиска вместо «СТОП», шкала P1 0…1, P2/CP/GI/CFO/очередь и предупреждение о потерях обработки.
- Тесты: закодированные P2/L1, все GI, FFT 16K/32K, четыре входные sample rate, L1-post созвездия/скремблирование, запись при переполнении очереди.

# 1.1.0

Исправления по сравнению с 1.0:
- Нормированная энергетическая корреляция P1 вместо абсолютного порога, пропускавшего слабый сигнал.
- Собственные копии I/Q-блоков в ограниченной очереди, без повторного использования занятого USB-буфера.
- Защита коррекции I/Q от деления на ноль после пустых отсчётов.
- Исправлены индексы одного PLP, различие PLP ID и позиции в массиве, обработка Q-компоненты без rotation.
- Исправлены размеры буферов LDPC и освобождение выровненной памяти.
- Обработка неполных SIMD-групп; нет ожидания ровно 32 FEC-кадров.
- Восстановлен внешний BCH-декодер с отбрасыванием неисправимых кадров.
- Восстановление TS через границы BBFRAME, Normal/HE, CRC заголовков и PSI.
- Полное завершение поточной цепочки при остановке и смене частоты.
- Копирование данных графиков до помещения в очередь GUI.
- Регулируемая длительность сканирования, список найденных сервисов, выбор PLP.
- Спектр до P1, расширенные счётчики, автоматический журнал, запись/чтение I/Q.
- VLC 3.0.23 включён в portable-пакет.
